# Иллюстрации к статьям

Как это работает: в каждой статье уже стоит место под картинку с нужным ID.
Сгенерируйте изображение по промпту ниже, сохраните файл **точно с этим именем**
(например `num-01.jpg`) в эту папку (`assets/img/articles/`) — картинка появится
на сайте автоматически, без правки кода. Пока файла нет, на его месте виден
аккуратный плейсхолдер с ID, так что редактор (Claude) тоже видит, что и куда
доставить.

Формат: JPG, размер строго **1200×800px** (соотношение 3:2), вес файла лучше
держать до 300–400 КБ (можно сжать на squoosh.app после генерации).

## Единый стиль для всех иллюстраций (вставлять в начало любого промпта)

> Минималистичная плоская иллюстрация в тёплой кремово-золотой палитре
> (фон #F6F2EA, акцент #BFA06B охристо-золотой, линии тёмно-коричневые #2E2A22),
> тонкие изящные линии, мягкие геометрические формы, элегантный эзотерический /
> астрологический стиль, спокойная премиальная атмосфера, **без текста и надписей
> на изображении**.
