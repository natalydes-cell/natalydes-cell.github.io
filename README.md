# Сайт (эзотерическая тематика) — инструкция

Сайт сделан на чистом HTML/CSS/JS — без сборки, без Node.js. Чтобы что-то поменять,
достаточно отредактировать файл и запушить в GitHub — дальше всё делается само.

## Структура папок

```
index.html              — главная страница
about.html               — страница "О сайте"
contacts.html             — контакты
articles/                — все статьи (по одному .html файлу на статью)
  _template.html          — шаблон для новой статьи, копировать и переименовывать
assets/css/style.css      — единый файл стилей (дизайн всего сайта)
assets/js/common.js       — общий файл: шапка, подвал, счётчик Метрики, рекламные блоки
robots.txt, sitemap.xml   — служебные файлы для поисковиков (sitemap.xml обновляется автоматически)
.github/workflows/deploy.yml — автопубликация на GitHub Pages при каждом пуше в main
```

## Как добавить новую статью

1. Скопировать `articles/_template.html`, переименовать файл (латиницей, без пробелов,
   например `articles/numerologiya-chislo-sudby.html`).
2. Открыть файл, поменять:
   - `<title>` — заголовок для поисковика (до ~60 символов, с ключевым словом),
   - `<meta name="description">` — краткое описание (до ~160 символов),
   - `<link rel="canonical">` — вписать реальный путь файла,
   - `<h1>` и текст статьи.
3. Закоммитить и запушить — через ~1 минуту статья появится на сайте, а `sitemap.xml`
   обновится автоматически (см. `.github/workflows/deploy.yml`).

## Как поменять дизайн (шапка/футер/цвета/реклама)

- Цвета, шрифты, отступы — всё в `assets/css/style.css`, один файл на весь сайт.
- Пункты меню в шапке, название сайта, ссылка на счётчик Метрики и рекламный блок —
  всё в `assets/js/common.js`, в объекте `SITE_CONFIG` в начале файла. Меняется
  один раз — применяется сразу ко всем страницам.

## Настройка Яндекс.Метрики

1. Зарегистрировать счётчик на https://metrika.yandex.ru
2. В `assets/js/common.js` вписать номер счётчика в `SITE_CONFIG.yandexMetrikaId`.

## Настройка рекламы (РСЯ)

1. Подать заявку на партнёрство в Яндекс.Рекламной сети (сайт должен быть какое-то
   время в открытом доступе и соответствовать правилам Яндекса).
2. После одобрения получить код рекламного блока в кабинете.
3. Вписать `SITE_CONFIG.yandexAdBlockId` и вставить реальный код в функцию
   `renderAdSlot()` в `assets/js/common.js` (место уже помечено комментарием).

## Хостинг и домен

Пока сайт лежит на GitHub Pages без своего домена. **Важно:** чтобы абсолютные пути
(`/assets/...`, `/articles/...`) сразу работали правильно без правок, репозиторий
на GitHub стоит назвать `<твой-логин>.github.io` — тогда сайт открывается прямо в
корне (`https://твой-логин.github.io/`), без лишней вложенной папки. Когда купишь
домен — просто добавляешь его в настройках репозитория (Settings → Pages → Custom
domain), ничего в коде менять не придётся.

Если репозиторий назвать иначе, GitHub Pages откроет сайт по адресу вида
`https://логин.github.io/имя-репозитория/`, и абсолютные пути `/assets/...`
будут вести не туда — в этом случае нужно будет поменять пути на относительные.

В `.github/workflows/deploy.yml` есть переменная `SITE_URL` (задаётся в
Settings → Secrets and variables → Actions → Variables репозитория) — впиши туда
финальный адрес сайта, она используется при сборке `sitemap.xml`.
